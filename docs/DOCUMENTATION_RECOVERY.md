# AGRI-CI — Récupération de la documentation

Si l'historique d'une conversation n'est plus accessible, ne pas reconstruire l'état du projet de mémoire uniquement.

Utiliser cet ordre :

1. `README.md` à la racine du dépôt ;
2. `docs/INDEX_DOCUMENTATION_FR.md` ;
3. `docs/PROJECT_STATUS.md` ;
4. `docs/HISTORIQUE_MAITRE_AGRI_CI.md` ;
5. `docs/GUIDE_UTILISATEUR_COMMERCIAL_PILOT_1_0_FR.md` ;
6. historique Git/GitHub Actions pour les détails techniques.

Les dépendances du monde réel sont suivies dans `docs/EXTERNAL_GO_LIVE_BLOCKERS.md`.

Cette procédure permet de reprendre AGRI-CI sans dépendre d'un chat précédent.
