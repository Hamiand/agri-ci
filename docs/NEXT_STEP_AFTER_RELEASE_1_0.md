# AGRI-CI — Prochaine étape après la barrière technique Release 1.0

Le développement autonome du cœur Release 1.0 ne doit pas être prolongé par des fonctions optionnelles avant le pilote.

La prochaine étape est de transformer les dépendances externes en décisions et preuves réelles, dans cet ordre pratique :

1. définir le produit et la zone du premier pilote ;
2. identifier les producteurs/cooperative et l'acheteur du pilote ;
3. confirmer le point de collecte et le transporteur ;
4. sélectionner le prestataire de paiement agréé compatible avec le contexte du pilote ;
5. sélectionner/provisionner l'infrastructure de production ;
6. effectuer les validations juridiques/confidentialité nécessaires ;
7. intégrer et certifier le prestataire de paiement sélectionné ;
8. effectuer sauvegarde/restauration et contrôles de production ;
9. faire une répétition contrôlée ;
10. exécuter une première transaction à petit volume et la rapprocher intégralement.

Ces étapes contiennent des décisions ou actions du monde réel. Elles ne doivent pas être simulées ou marquées terminées uniquement à partir du dépôt logiciel.
