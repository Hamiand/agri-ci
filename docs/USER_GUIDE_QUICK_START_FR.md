# AGRI-CI — Démarrage rapide utilisateur

Ce résumé ne remplace pas le guide complet.

## Producteur

1. Se connecter avec le rôle Producteur.
2. Déclarer une récolte future réaliste.
3. Créer une offre sans dépasser la quantité disponible.
4. Consulter les demandes pertinentes.
5. Examiner puis accepter/refuser l'engagement proposé.
6. Remettre la quantité réelle au point de collecte et vérifier le poids enregistré.
7. Suivre l'historique de règlement et vérifier le montant net.

## Acheteur

1. Se connecter avec le rôle Acheteur.
2. Publier une demande réelle.
3. Suivre l'agrégation.
4. Créer la commande uniquement lorsque la barrière d'agrégation est satisfaite.
5. Suivre collecte, qualité, transport et livraison.

## Opérations

1. Enregistrer la quantité réellement collectée et le vrai point de collecte.
2. Enregistrer le contrôle qualité.
3. Créer les lots traçables.
4. Affecter les lots à un transporteur autorisé.
5. Enregistrer le départ réel.
6. Confirmer la quantité réellement livrée.
7. Préparer le règlement uniquement sur le livré non encore réglé.
8. Rapprocher quantité, montant, ledger et référence du prestataire.

## Règle essentielle

**Ne jamais modifier la réalité pour faire correspondre les chiffres.** En cas d'écart, conserver les preuves, arrêter l'augmentation du pilote et déclencher le contrôle prévu.
