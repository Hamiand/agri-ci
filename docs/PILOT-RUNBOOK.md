# AGRI-CI Pilot Operations Runbook

Morning: verify system readiness, active demand, harvests approaching, collection capacity,
vehicles, unresolved disputes and payment failures.

Collection: identify farmer and allocation, weigh actual quantity, photograph/record evidence
when required, grade A/B/C, create traceable lots.

Dispatch: verify lot/order, vehicle and driver, assign once, record departure.

Delivery: record received quantity and receiver, investigate shortages before settlement.

Settlement: reconcile allocation → collection → delivery, prepare farmer net amount, send
through licensed payment partner, reconcile signed provider callback.

End of day: unresolved collections, in-transit vehicles, delivery differences, failed payments,
security alerts, backup status, next-day demand/capacity.
